## Six-minute live flow

| Time | Show |
|---|---|
| 0:00–0:40 | Real problem: checking a paper is hard when claims, data and code are separated. Drop the synthetic project ZIP. |
| 0:40–1:20 | Automatic inventory and the actual evidence graph. Open a source and its immutable hash. |
| 1:20–2:20 | Paper/result difference; explain the source correspondence question and uncertainty. |
| 2:20–3:20 | Generalization sample: answer “New individuals.” Explain why the human is required. |
| 3:20–4:20 | Actual baseline and grouped run, environment manifest and measured difference. Label reconstruction honestly. |
| 4:20–5:10 | Clean control, incompatible contexts, and missing evidence. Accept/revise a finding. |
| 5:10–6:00 | Mobile source/review/export, public Alternate Clouds URL, and impact. |

If the isolated runner is unavailable, fix that before recording. Do not turn a saved synthetic result into a claimed new execution. If displaying a recorded run, show its timestamp, provider and input hash.
