# Implemented non-deployment release

## Evidence and persistence

Private intake → immutable snapshot → bounded discovery/parsing → source claims → deterministic checks → grounded investigation → isolated computations → scientific decisions → versioned review/report.

FastAPI serves React production assets and the API from one origin. SQLAlchemy persists cases, artifacts, durable jobs/events and executions. Claims, anchors, checks, graph links, scientific questions and historical findings use atomic JSON checkpoints. SQLite/private files are the validated local profile; PostgreSQL/private Supabase adapters are available for deployment configuration. One durable worker operates independently of HTTP request lifetimes.

Artifacts retain original bytes and SHA-256. ZIP paths/expansion/entries/files and secret-bearing names are bounded. Public GitHub acquisition pins commits, respects rate limits and uses constrained destinations. Recognized linked papers have redirect limits. Git hooks, submodules, LFS retrieval and dependency installation are excluded. Offline mode prevents external acquisition.

## Automatic scientific discovery

Every accepted source is inventoried; 100 prioritized artifacts receive inspection. A sole separately uploaded PDF establishes the primary paper. Multiple ambiguous papers, entry points, datasets, targets or feature policies trigger focused choices. Figures/logos have separate inferred roles. Missing evidence and uninspected files remain visible.

Parsers handle PDF passages/tables, Python AST/notebook cells and saved outputs, CSV/TSV schemas/predictions, and JSON/JSONL/YAML/TOML results/configuration. Anchors record pages/table boxes, lines/cells, structured pointers, dataset summaries or execution IDs. Original PDF pages render on demand with word/table overlays. Parser subprocesses have time/output/resource limits and no service credentials. Linux uses resource limits; Windows uses memory/CPU/process-bounded job objects with kill-on-close.

Scanned-page recovery uses at most six hosted vision attempts per case. Recovered passages carry OCR provenance and require human confirmation before their quantities can verify a discrepancy. Failed/unreadable pages remain visible. Offline/text-only local inference never silently claims vision support.

Explicit numerical claims use units, reported precision and available dataset/model/split/averaging/version/seed/population context. Multiple released values require a trial/aggregation interpretation; actual mean/best arithmetic follows that answer. Checks cover recognizable metric/table/count/confusion-matrix/improvement forms, saved-result/config/protocol differences, trial coverage, partition duplicates, entity overlap, explicit preprocessing data flow, target-derived features and domain-dependent time/feature questions. These are defined patterns, not universal scientific understanding.

## Models and adaptive tools

GPT-6 Luna is the hosted default. OpenAI Responses and Ollama share validated schemas, bounded retries and reachable-provider fallback. Exact-quote and artifact-reference validation grounds extracted claims. Numerical verification independently parses quantities. The model cannot assign verified statuses or measured values.

The bounded investigator can inspect/search sources, request real allowlisted check families, re-extract claims and ask sourced scientific questions. Questions affect interpretation, feature exclusion, source correspondence or corrected plans. Unknown paths, fabricated quotations and unsupported tools are rejected. Provider budgets/actions/checkpoints persist. Source material remains untrusted data.

## Isolated experiments and human decisions

Supported original CPU scripts/notebooks execute with preinstalled numeric libraries in disposable environments. Static guards reject unsupported imports, reflection, dynamic execution and process operations. Metric instrumentation preserves arguments/results. Notebook display-only/path repairs are recorded. Runtime controls restrict source writes, generated-output destinations, network/process operations and logs. Returned metrics/folds/split counts, versions, source/data/worker/helper hashes and sandbox references establish provenance.

Trusted reconstructions cover explicit tabular inputs and supported scikit-learn estimators. Cross-validation preserves established splitter/scoring settings and returns real fold measurements. Group, time, combined group/time, unavailable-feature and training-only-preprocessing corrections are explicitly separate protocols. Unsupported transformations or unresolved scientific assumptions do not receive silent repairs.

The OpenAI profile uses 1 GB memory, disabled network and a forced single exact trusted coordinator call. Measurements are downloaded files, never model summaries. A 90-second variant budget applies, with actual teardown on completion/cancellation/timeout. Docker/E2B/broker profiles support their configured environments. Research programs never execute on the application host.

Human answers are versioned; changed answers invalidate dependent results and retain previous findings. Completed execution fingerprints are reused. Paper-to-original-run comparisons require scientific correspondence. Saved-artifact discrepancies, reproduction differences and corrected evaluations remain separate. There is no research trust score or misconduct verdict.

## Recovery and interface

Startup reconciles recorded environments before up to two bounded continuations within the case time budget. Recoverable measurement files must match stored hashes. Cancellation/deletion terminate active computation. SSE event IDs support reconnect/replay. Signed private cookies, ownership checks, retention and source/report deletion apply across endpoints.

The restored responsive UI uses local fonts, Motion transitions, lazy Three.js graphics, a complete 2D graph, real clustering and virtual lists. PDF/JSON/ZIP reports include coverage, evidence, questions/reviews, immutable sources, manifests and actual measured outputs/logs.

## Support boundaries and external validation

Excluded: universal arbitrary-repository reproduction, GPU/deep-learning/R execution, blind dependency installation, literature-wide verification, arbitrary publisher crawling, universal figure/table/program-analysis semantics, public sharing, author contact and misconduct assessment. Scientific correspondence and absent evidence remain real limits.

Live acceptance used OpenAI and SQLite/filesystem persistence. Ollama/Docker/E2B/cloud persistence, physical devices and the excluded deployment require their actual environments for live certification. Controlled adapter tests are not represented as live service tests. See VALIDATION.md and REMAINING_WORK.md.
